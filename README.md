実行ファイルはbin/Debug/net9.0-windows/CustomerManagement.exeです。<br><br>

# 機能一覧
<br>・登録ボタン：名前、年齢、性別を入力して、登録ボタンをクリックすると、顧客テーブルにレコードが登録されます。<br><br>
・編集ボタン：ID、名前、年齢、性別を入力し、編集ボタンをクリックすると、指定したIDのレコードを編集できます。 <br><br>
・削除ボタン：IDを入力して削除ボタンをクリックすると、指定したレコードを削除できます。 <br><br>
・クリアボタン：ID、名前、年齢、性別を入力した状態でクリアボタンをクリックすると、入力データがクリアされます。<br><br>
