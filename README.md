# The View
WPF(Windows Presentation Foundation)を使って、シンプルな顧客管理システムを作りました。

実行ファイルはCustormerManagement/bin/Debug/net9.0-windows/CustomerManagement.exeです。

# 機能一覧

登録ボタン：名前、年齢、性別を入力して、登録ボタンをクリックすると、顧客テーブルにレコードが登録されます。

編集ボタン：ID、名前、年齢、性別を入力し、編集ボタンをクリックすると、指定したIDのレコードを編集できます。 

削除ボタン：IDを入力して削除ボタンをクリックすると、指定したレコードを削除できます。 

クリアボタン：名前、年齢、性別を入力した状態でクリアボタンをクリックすると、入力データがクリアされます。
